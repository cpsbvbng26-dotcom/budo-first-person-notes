利益相反の記録は、扱う場合の条件を次のように書いています。

- 扱うとすれば、当事者記録としてだけです。
- 立場と師弟関係を開示します。

この記録は、上の条件をすべて満たす形にしています。

## 扱わないこと

- 氣の効果について、何も主張しません。肯定も否定もしません。
- 流派の教えや技の説明を、一般の知識で書き足しません。
- 師範の名と、師範を特定できる言い方を書きません。ほかの門人の名も書きません。
- Sophaxis のことは、この記録では扱いません。
- 氣の原理を、独学の系列の研究の主題にしません。

## 記録の形

体験の記録の項目は、次の欄を持ちます。

| 欄 | 中身 |
| --- | --- |
| `id` | 番号。E から始まる |
| `kind` | 種類。下の表のどれか |
| `ja`・`en` | 私を主語にした文。運営者が公開の記録で述べたこと |
| `sources` | `verification/sources.json` の引用の名 |

| `kind` | 意味 |
| --- | --- |
| `statement` | 本人が述べたこと |
| `self-reported` | 本人の申告。級と免状の日付 |
| `own account` | 本人の受け止め。確かめた事実ではないという断りを同じ項目に持つ |

検証の項目は、`id`・`about`・`ja`・`en`・`status` の欄を持ちます。
`status` は、いまはどれも `not done` です。
体験の項目は検証の欄を持たず、検証の項目は体験の文を持ちません。

## 検査

```
python3 verification/check.py            # 記録の欄・出どころの引用・年数と級・体験と検証の分け方・開示・人名・写し・書き方・数
python3 verification/check.py --online   # 出どころの頁を cpsbvbng26-dotcom の main から取り寄せ直し、引用がいまもあるかを見る
python3 verification/check.py --break    # 検査を一つずつ壊し、落ちることを確かめる
```

CI は、外へ出ない検査と壊して確かめる検査を、push と PR のたびに回します。
取り寄せ直す検査は、別の仕事として同じときと週に一度回します。
